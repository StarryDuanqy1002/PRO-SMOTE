## PRO-SMOTE

> 
> Paper Title: PRO-SMOTE: A Structure-Driven Framework for Robust Oversampling in Imbalanced Classification
> Journal: International Journal of Machine Learning and Cybernetics

### Code Statement

This repository contains the experimental code for the paper **PRO-SMOTE: A Structure-Driven Framework for Robust Oversampling in Imbalanced Classification**.
The source code, datasets, experimental scripts and dependency documents are still under organization, cleaning and annotation. The code is not available for the time being.
After the paper is accepted, we will standardize the code, remove sensitive contents and update this repository with the full reproducible version for research reproduction.
